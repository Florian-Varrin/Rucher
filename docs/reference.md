# Reference

Commands, MCP tools, statuses, files and environment variables of Rucher. For the workflow see [workflow.md](workflow.md); for sessions see [sessions.md](sessions.md); for notes see [memory.md](memory.md).

## CLI

Every command that acts on a group takes `-g, --group <name>`. Without it the group comes from the session, `RUCHER_GROUP`, the run directory you are in or the repo you are in (longest path); when the directory decided, the command says so on stderr: `group shop (from api)`. A repo of several groups with nothing else to go by is an error naming them.

| Command                                                                                               | Does                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ----------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `rucher groups list`                                                                                  | the groups of the machine (the folders of `~/.config/rucher/groups/`), with their repo count, their sessions that are not archived and their run directory                                                                                                                                                                                                                                                                                         |
| `rucher groups create <name> [--repos a,b]`                                                           | creates the definition (`group.json` and an empty `CLAUDE.md`, name `[a-z0-9-]+`) and renders the run directory; its first session must accept Claude Code's trust prompt for the run directory settings to apply                                                                                                                                                                                                                                  |
| `rucher groups rename <old> <new>`                                                                    | renames the definition and the group in Carnet; the run directory keeps its path, so transcripts stay where they are; refused while a session of the group runs                                                                                                                                                                                                                                                                                    |
| `rucher groups drop <name> [--purge]`                                                                 | archives the sessions of the group and removes its definition; notes and run directory stay (recreating the name shows them again); `--purge` also deletes the notes and the run directory; refused while a session of the group runs                                                                                                                                                                                                              |
| `rucher group show` / `path [--def \| --run]`                                                         | the group: name, definition, run directory and repos; `path` prints the run directory (or the definition, with `--def`) alone, for `cd "$(rucher group path)"`                                                                                                                                                                                                                                                                                     |
| `rucher group add <path>` / `remove <path>`                                                           | adds or removes a repo in `group.json`, then renders the run directory                                                                                                                                                                                                                                                                                                                                                                             |
| `rucher group sync` / `edit [--json]`                                                                 | `sync` renders the run directory; `edit` opens the instructions (or `group.json`) in `$VISUAL`, `$EDITOR` or `vi`, checks `group.json` (edit again or restore it), then syncs                                                                                                                                                                                                                                                                      |
| `rucher status [--session X] [--all]`                                                                 | agent status of the default session (most recently active, re-resolved on every repaint) or of a named one, its name and the group whose database it reads on the clock line (`16:41 - shop-auth · shop`; an archived session says so); `--all` shows every session with open agents, a table line or note activity, most recent first, each headed by its name, with the clock and the group on top and one legend at the bottom                  |
| `rucher status --watch [--interval s]`                                                                | same, repainted when the output changes, for the dedicated pane; in a terminal, keys on the displayed session: `n` unfold the notes, arrows select, `enter` detail, `d` drop with a reason, `q` quit (see [memory](memory.md))                                                                                                                                                                                                                     |
| `rucher log [--session X] [-n 20]`                                                                    | latest journal events                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `rucher log --md [--session X]`                                                                       | journal as markdown, one line per event with commit and report link, for archiving in a repo                                                                                                                                                                                                                                                                                                                                                       |
| `rucher log --agents`                                                                                 | agent events only, without the `session.*` starts and ends                                                                                                                                                                                                                                                                                                                                                                                         |
| `rucher sessions [--all]`                                                                             | active sessions: name (or short id), kind, status, repo-relative cwd, last activity, open agents, purpose; `--all` adds temp and archived ones                                                                                                                                                                                                                                                                                                     |
| `rucher sessions merge <from> <into>`                                                                 | moves agents (a name already used in `into` is closed in `from`), events and the table line (when `into` has none) into `into`, carries the name when `into` has none, then drops `from`; nothing merges automatically                                                                                                                                                                                                                             |
| `rucher sessions move <session> --to <group> [--merge] [--dry-run]`                                   | changes the group of a session (a group name); its agents, table line and journal follow it, its notes stay in their group; a target with a session of the same name is refused unless `--merge`, which joins them                                                                                                                                                                                                                                 |
| `rucher sessions rename <session> <name>`                                                             | renames a session that is not running; the next `rucher resume` passes the name to Claude Code                                                                                                                                                                                                                                                                                                                                                     |
| `rucher sessions promote <session> [<name>]` / `demote <session>`                                     | temp to active (a name is needed when it has none) / active to temp, keeping the name                                                                                                                                                                                                                                                                                                                                                              |
| `rucher sessions drop <session> [--purge]`                                                            | archives the session and closes its agents; `--purge` also deletes its host transcript and prints each deleted path                                                                                                                                                                                                                                                                                                                                |
| `rucher sessions clean [--older-than 7d] [--purge] [--dry-run]`                                       | archives temp sessions idle longer than the delay (`30m`, `12h`, `7d`), work or not; `--purge` deletes their transcripts; resets `running` sessions whose host process is gone to `idle`                                                                                                                                                                                                                                                           |
| `rucher notes [--all] [--kind K] [--repo R] [--general] [--stale] [--md]`                             | the group's notes by kind (dead ends, decisions, learnings), most cited first; `--all` adds dropped ones with their reason, `--stale` lists notes older than 40 active days never or no longer cited, `--md` prints a Markdown view                                                                                                                                                                                                                |
| `rucher notes show <id>` / `add <kind> <text> [--repo R]…` / `drop <id> --reason R [--replaced-by N]` | a note with its repos, weight and citations; adds a note by hand (refused over 200 characters, with markdown, or with a repo not in the group; a near duplicate is added and flagged); closes a note, kept in the history                                                                                                                                                                                                                          |
| `rucher new <name> [-- args]`                                                                         | creates an active session, renders the group's run directory and starts Claude Code for it there, or in the current directory outside any group (`--session-id`, `--name`); arguments after `--` go to Claude Code                                                                                                                                                                                                                                 |
| `rucher tmp [<name>] [-- args]`                                                                       | same for a temp session, named or not                                                                                                                                                                                                                                                                                                                                                                                                              |
| `rucher resume [<session>] [-- args]`                                                                 | runs the session host's resume command (`claude --resume <id> --name <name>`) from its recorded cwd after rendering its group's run directory, and fails with `SESSION_CWD_MISSING` when that directory is gone; without a session, picks one from the group (fzf when installed, else a numbered list)                                                                                                                                            |
| `rucher fork <session> [<name>] [--active] [-- args]`                                                 | branches a session with `--fork-session` into a new temp session (active with `--active` and a name); the SessionStart hook links it to its parent                                                                                                                                                                                                                                                                                                 |
| `rucher hook session-start`                                                                           | hook entry point, reads the hook JSON on stdin, records the session and the rules version in effect; adds the resume context on `source: resume`, the group's notes (see [memory](memory.md#how-notes-reach-a-session)), the rules after a compaction of a session launched without them, a warning for a session never started by `rucher`, and prints `rules updated` on stderr when they changed since; exits 0 outside a group or on any error |
| `rucher hook session-end`                                                                             | marks the session idle with `ended_at` and a `session.ended` event, once (the launcher does the same at exit); no output, exits 0 in every case                                                                                                                                                                                                                                                                                                    |
| `rucher hook user-prompt-submit`                                                                      | syncs the Claude session title to the session name and marks the day as active on every prompt; no output, exits 0 in every case                                                                                                                                                                                                                                                                                                                   |
| `rucher hook post-tool-use`                                                                           | adds a repo's notes the first time a `Read`, `Edit`, `Write`, `Grep`, `Glob` or `Bash` call touches that repo, once per session; silent for subagents and outside the repos; exits 0 in every case                                                                                                                                                                                                                                                 |
| `rucher hook subagent-start`                                                                          | pairs the started subagent with a running Carnet agent in start order, provisionally; exits 0 in every case; gives named sub-agents (not forks) short reporting rules as context                                                                                                                                                                                                                                                                   |
| `rucher hook subagent-stop`                                                                           | re-pairs by name (the Agent description, else the prompt's ``You are fork `<name>` ``), then moves the agent still `running` to `review`; exits 0 in every case                                                                                                                                                                                                                                                                                    |
| `rucher serve`                                                                                        | the stdio MCP server; the group is resolved lazily so the server always starts, tools answer `NO_GROUP` outside a group, and `GROUP_AMBIGUOUS` in a repo shared by several groups when nothing pins the session                                                                                                                                                                                                                                    |
| `rucher complete <shell>`                                                                             | prints the completion script for zsh, bash, fish or powershell (`source <(rucher complete zsh)`); `rucher complete -- <words>` answers the shell with commands, flags, session names and short ids, group names and repo paths; silent outside a group                                                                                                                                                                                             |

Default session: the most recently active one of the current group. It changes whenever another session becomes active, which is why every view names its session.

`rucher status` format:

```
16:41 - shop-auth · shop

On the table
  ⚙️ Step 11 Preview/Run — applying (main working, not ready)

Waiting on you
  1. 👀 setParent fix (develop) — review, name branch

Running
  ⏳ Step 13 — bricks moved to sidebar

Notes
  + #31  dead_end  similar to #12 · tenant SSR cache: key too wide, leaks between tenants
  ★ #14  cited     avoided the Workers migration

⚙️ main working · 💬 discussing · ❓ answer · 👀 review · 📥 apply · 🧪 test · ✅ commit · 🌿 branch · ⏳ running
```

The "Notes" section lists the notes the session added (`+`), cited (`★`) and dropped (`−`), most recent first; it folds to one summary line beyond five lines and is absent when the session touched no note (see [memory.md](memory.md)).

The clock line names the group whose database is read, so a session recorded in another group than expected shows at once; the repo-relative cwd is in `rucher sessions`. With `--all`, the first line holds the clock and the group (`16:41 - shop`) and each session block starts with its name, with the notes summary line only. On a narrow terminal only the group is cut, never the clock or the name; a note line keeps its `similar to #N` warning and cuts its text.

## MCP tools

The Carnet MCP server (`rucher serve`, wired by the plugin) gives the agents these tools. All take `session` as an optional override (name, id or id prefix). Each returns short text only, no structured content, so results stay small in the model's context; rule violations come back as tool errors with a code. Through the plugin, Claude Code names them `mcp__plugin_rucher_carnet__<tool>`.

**Agents**

| Tool            | Parameters                          | Effect                                                                                                                                                                                                                                                                                        |
| --------------- | ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `agent_start`   | name, task, base_commit?, worktree? | creates the agent as ⏳ running, logs `started`, returns the report destination `<run directory>/reports/<name>.md` (absolute; none outside any group)                                                                                                                                        |
| `agent_update`  | name, status, note?, report_path?   | changes the status and the displayed text (a running note is cleared when the status leaves running without a new note); for moves `agent_step` does not cover                                                                                                                                |
| `agent_done`    | name, report_path, has_questions    | copies the report to `<run directory>/reports/<name>.md` and records that path (outside any group, keeps the fork's path); stores ❓ answer or 👀 review, published at the real stop (SubagentStop) or at once when unpaired; logs `finished` then                                            |
| `agent_step`    | name, step, commit?, note?, next?   | one call per step: `answered` (→ apply), `applying` (⚙️ table line), `applied` (→ test), `tested` (→ commit) log the event, move the agent and set the table line; `committed` (commit required) and `dropped` (note = reason) close it and clear its table line; `next` overrides the status |
| `agent_drop`    | name, reason?                       | sets `closed`, logs `dropped`                                                                                                                                                                                                                                                                 |
| `agent_list`    | —                                   | one line per open agent, so the main agent knows where it stands                                                                                                                                                                                                                              |
| `queue_reorder` | names[]                             | order of "Waiting on you"                                                                                                                                                                                                                                                                     |

**On the table**

| Tool          | Parameters                   | Effect                                                                                                                                                                                              |
| ------------- | ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `table_set`   | text, main_working?, status? | the "On the table" line, ⚙️ when main_working, else the emoji of `status` (default 💬); `status` is refused together with main_working; main_working omitted is false with a status, else unchanged |
| `table_clear` | —                            | empties the section                                                                                                                                                                                 |

**Sessions**

| Tool                  | Parameters                       | Effect                                                                                                                                                                                          |
| --------------------- | -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `session_new`         | name, purpose?                   | names or renames the current session and makes it `active`; `SESSION_NAME_TAKEN` only when another session has the name; the result asks the human to `/rename` the Claude session the same way |
| `session_list`        | include_temp?, include_archived? | sessions by last activity, with kind and status, the current one marked                                                                                                                         |
| `session_resume_info` | name?                            | status view, last events and the resume command (current session by default)                                                                                                                    |
| `session_drop`        | name                             | by name, id or id prefix: status `archived`, agents closed                                                                                                                                      |

**Memory**

| Tool        | Parameters                                       | Effect                                                                                                                                    |
| ----------- | ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `note_add`  | kind, text, repos?, agent?                       | main agent only: adds a note (learning, decision, dead_end) to the group; returns the similar active notes when it looks like a duplicate |
| `note_list` | kind?, repo?, general?, query?, include_dropped? | active notes, dead ends first, most cited first; `query` is a substring                                                                   |
| `note_drop` | id, reason, replaced_by?                         | main agent only: closes a note, kept with its reason and replacement                                                                      |
| `note_cite` | id, why, agent?                                  | records that a note changed what the agent did; one citation per session counts for the weight                                            |

**Journal**

| Tool        | Parameters                          | Effect                                           |
| ----------- | ----------------------------------- | ------------------------------------------------ |
| `log_event` | type, agent?, commit?, link?, note? | appends a line to the journal                    |
| `log_read`  | limit? (1–200, default 20)          | latest entries, oldest first, to rebuild context |

## Statuses

### Sessions

| Field  | Values                        | Meaning                                                                         |
| ------ | ----------------------------- | ------------------------------------------------------------------------------- |
| kind   | `temp`, `active`              | whether the session is worth keeping; an `active` session always has a name     |
| status | `idle`, `running`, `archived` | whether a Claude process is attached; `archived` = closed, hidden, journal kept |

Session lifecycle events in the journal: `session.started`, `session.resumed`, `session.forked` (written by the `SessionStart` hook), `session.ended`. `log_event` only accepts agent events.

### Agents

| Status       | Emoji | Who acts                                                |
| ------------ | ----- | ------------------------------------------------------- |
| running      | ⏳    | fork in the background                                  |
| discussing   | 💬    | user                                                    |
| answer       | ❓    | user                                                    |
| review       | 👀    | user                                                    |
| apply        | 📥    | user                                                    |
| test         | 🧪    | user                                                    |
| commit       | ✅    | user                                                    |
| branch       | 🌿    | user                                                    |
| closed       | —     | terminal, hidden from `rucher status`, kept for history |
| main_working | ⚙️    | main (only on the "On the table" line)                  |

Rules enforced by the server:

- User-action emojis are refused for the main agent's own work.
- A note longer than 60 characters is truncated; paths and backticks are stripped. Applied to agent names, notes and the table text.
- Order of "Waiting on you": answer first, then review in plan order, then the rest; `queue_reorder` can override it.
- Agents are never deleted: `agent_drop` closes them, and events keep the history.

## Files and directories

Rucher follows the XDG base directories, per user. `RUCHER_HOME=<dir>` puts everything under `<dir>/config`, `<dir>/data`, `<dir>/state` and `<dir>/run` instead.

| Path                                                | Holds                                                                                                                                                                                                                             |
| --------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `~/.config/rucher/groups/<name>/group.json`         | the group: `name`, `workspace` (the run directory, absolute, fixed at creation), `repos` (`{ path, name }`, `~` allowed, name defaults to the folder name), `backends` (per host id, `settings` merged into the generated config) |
| `~/.config/rucher/groups/<name>/CLAUDE.md`          | the group's instructions, or `AGENTS.md` to keep them neutral (one or the other), edited by hand (`rucher group edit`), versionable                                                                                               |
| `~/.config/rucher/groups/<name>/backends/claude.md` | with `AGENTS.md`: instructions for Claude Code only, optional                                                                                                                                                                     |
| `~/.config/rucher/groups/<name>/prompt.md`          | rules of the group, added to the system prompt of its sessions after the core rules                                                                                                                                               |
| `~/.config/rucher/prompt.md`                        | replaces the core rules for every group                                                                                                                                                                                           |
| `~/.local/share/rucher/carnet.db`                   | the single SQLite database of every group: sessions, agents, the "On the table" line, the journal, the notes and which repos' notes each session already got (WAL mode)                                                           |
| `~/.local/share/rucher/workspaces/<name>/`          | the group's run directory, the cwd of its sessions, never edited by hand; its path never changes, since Claude Code files transcripts by cwd                                                                                      |
| `<run directory>/*.md`                              | generated copies of the definition's `.md` files except `prompt.md`, each starting with `<!-- generated by rucher, do not edit -->`; with `AGENTS.md`, also `backends/claude.md` and a generated `CLAUDE.md` of imports           |
| `<run directory>/.claude/settings.json`             | generated (`"//": "generated by rucher, do not edit"`): `permissions.additionalDirectories` from the repos, a `permissions.deny` `Edit(/<file>)` rule per copy, then `backends['claude-code'].settings`                           |
| `<run directory>/reports/`                          | fork reports, `<name>.md`                                                                                                                                                                                                         |
| `~/.local/state/rucher/prompts/`                    | the assembled system prompt append of each session, `<session id>.md`, rewritten at each launch                                                                                                                                   |

A group exists when its `group.json` does: the folder name is the group's name (`[a-z0-9-]+`). Rendering the run directory (`rucher group sync`, and every `new`, `tmp`, `resume` and `fork`) writes only the instruction copies and the generated settings; everything else in the run directory is left alone. Nothing is written inside the repos.

## Environment variables

| Variable                                                                | Effect                                                                                                                                                         |
| ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `RUCHER_HOME`                                                           | puts every Rucher location under one directory (`config`, `data`, `state`, `run`), for tests                                                                   |
| `XDG_CONFIG_HOME`, `XDG_DATA_HOME`, `XDG_STATE_HOME`, `XDG_RUNTIME_DIR` | the standard base directories (defaults `~/.config`, `~/.local/share`, `~/.local/state`; `run` falls back to the state directory); relative values are ignored |
| `RUCHER_PURGE_DAYS`                                                     | idle days before sessions without work are purged at session start (default 3; a positive number, fractions allowed)                                           |
| `RUCHER_SESSION_ID`                                                     | set by `rucher new`, `tmp` and `resume` on Claude Code to the session's id; for `rucher fork`, the parent's id, which links the branch to it                   |
| `RUCHER_SESSION_NAME`                                                   | the session's name, empty when unnamed                                                                                                                         |
| `RUCHER_SESSION_KIND`                                                   | set by `rucher fork` only: the kind (`temp` or `active`) of the branch                                                                                         |
| `RUCHER_GROUP`                                                          | set by `rucher` on launch when the session has a group: the group's name                                                                                       |
| `CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD`                          | set to `1` by `rucher` on launch, so Claude Code loads the `CLAUDE.md` of each repo it passes with `--add-dir`                                                 |
| `RUCHER_PROMPT_VERSION`                                                 | set by `rucher` on launch: the version of the rules in the append, recorded at session start, compaction, clear and fork                                       |
| `RUCHER_MEMORY_HALF_LIFE_DAYS`                                          | active days after which a note citation counts half in its weight (default 20)                                                                                 |
| `RUCHER_MEMORY_MAX_CHARACTERS`                                          | characters of each memory injection at session start or on a repo's first use (default 2000)                                                                   |
